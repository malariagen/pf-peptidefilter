# Pf-PeptideFilter

A Streamlit-based interactive web application for filtering and analyzing *Plasmodium falciparum* peptide candidates for vaccine development. This tool provides comprehensive filtering capabilities based on human identity, strain conservation, gene expression, homology, and indel frequency.

## Features

- **Human Identity Filtering**: Filter peptides based on sequence identity and alignment length with human proteins
- **Strain Conservation Analysis**: Assess amino acid haplotype frequency and conservation across field samples
- **Indel Frequency Filtering**: Control for insertion/deletion polymorphisms and frameshifts
- **Gene Expression Filtering**: Select candidates based on expression across liver stages (D2-D6) and sporozoite stage
- **Homology Filtering**: Identify orthologs in other *Plasmodium* species (*P. berghei*, *P. vivax*, *P. knowlesi*)
- **Enrichment Analysis**: GO term enrichment analysis for cellular component localization
- **Diagnostic Plots**: Visual exploration of gene size distributions across filtering steps
- **Data Export**: Download filtered gene and peptide datasets with customizable formats
